# Code Of Conduct

Please keep localization discussions respectful and practical.

## Expected Behavior

- Be polite when suggesting corrections.
- Explain wording changes with context.
- Respect native speakers and regional language differences.
- Stay focused on localization quality.

## Not Accepted

- Harassment or personal attacks.
- Insults based on language, nationality, identity, or skill level.
- Spam or unrelated promotion.
- Repeatedly pushing changes after a maintainer has rejected them.

Maintainers may close issues, reject pull requests, or block contributors when needed to keep the repository useful and safe.
